# ADR-003: 邮件模板编辑器方案

## Status
Accepted

## Context
管理员需要编写邮件模板，模板使用 Jinja2 语法嵌入动态变量（如 `{{ machine_model }}`、`{{ private_ip }}`）。需要支持模板的编写、预览、版本管理。

两种业界路线：可视化拖拽编辑器 vs 代码编辑器+实时预览。

## Decision

采用 **Monaco Editor（代码编辑器）+ Jinja2 后端实时渲染预览**。

### 方案对比

| 对比项 | Monaco + 后端渲染 | 可视化拖拽（MJML/Vue Email Editor） |
|--------|-------------------|-----------------------------------|
| Jinja2 变量支持 | ✅ 原生支持 `{{ var }}` 语法 | ❌ 无法嵌入模板变量 |
| 适用场景 | 事务型邮件（带动态数据） | 营销型邮件（固定内容） |
| 模板精确控制 | ✅ 手写 HTML+CSS，像素级控制 | ⚠️ 受限于组件库 |
| 学习成本 | 需懂 HTML+Jinja2 基础 | 低，非技术人员也能用 |
| 本场景匹配度 | ✅ 高 | ❌ 低 |

### 架构设计

```
┌──────────────────────────────────────────────┐
│              模板编辑页（前端）                 │
├────────────────────┬─────────────────────────┤
│  Monaco Editor     │  实时预览 (iframe)       │
│  • HTML 语法高亮   │                         │
│  • Jinja2 语法提示 │  调用 POST /api/        │
│  • 自动补全        │  templates/preview      │
│  编辑内容 +        │  → 后端 Jinja2 渲染     │
│  示例数据 JSON     │  → 返回 HTML            │
│                    │  → iframe 展示          │
├────────────────────┴─────────────────────────┤
│  示例数据编辑区（JSON，用于填充预览变量）        │
│  {"machine_model":"Dell R740","private_ip":...}│
└──────────────────────────────────────────────┘
```

### 预览 API 设计

```
POST /api/templates/preview
Request:
{
  "subject_tpl": "您的服务器 {{ machine_model }} 已开通",
  "body_html": "<h2>尊敬的客户</h2><p>IP: {{ private_ip }}</p>",
  "sample_data": {
    "machine_model": "Dell R740",
    "private_ip": "10.0.0.1"
  }
}

Response:
{
  "subject_rendered": "您的服务器 Dell R740 已开通",
  "body_rendered": "<h2>尊敬的客户</h2><p>IP: 10.0.0.1</p>"
}
```

### 安全措施

- 后端渲染使用 Jinja2 `SandboxedEnvironment`，限制模板可访问的属性
- 仅注入预定义的变量白名单（租赁记录字段），禁止执行任意 Python 代码
- 前端 Monaco Editor 禁用外部资源加载

### 预览触发策略

- 用户停止输入 800ms 后自动触发预览（debounce）
- 同时提供「手动刷新预览」按钮
- 预览失败时在预览区显示错误信息（不阻塞编辑）

## Consequences

### 变得容易
- 模板变量精确控制，每个字段都能独立占位
- 管理员可以复用 HTML 邮件模板（从网上找现成的邮件 HTML 后粘贴修改）
- 预览即时反馈，降低模板编写错误率

### 变得困难
- 管理员需要懂基本 HTML 和 Jinja2 语法（但门槛很低）
- Monaco Editor 打包体积较大（~5MB gzip），首次加载稍慢
- 后端每次预览都需要 Jinja2 渲染，有一定 CPU 开销（但可忽略）

### 可逆性等级：高
- 后续如需增加可视化编辑器，可与现有方案并存（不同模板类型选不同编辑器）
