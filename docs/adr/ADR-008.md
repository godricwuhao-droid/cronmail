# ADR-008: 算力租赁合同续期功能

## Status
Proposed

## Context

算力租赁合同到期后需要续期。续期不是简单延长到期时间，而是创建一份新合同，同时需要追溯与原合同的延续关系。续期合同应能沿用原合同的关联设备。

## Decision

### 1. 模型新增 `renewed_from_id`

`Contract` 表新增一个自引用外键：

```python
renewed_from_id = Column(UUIDColumn(), ForeignKey("contract.id"), nullable=True, comment="续期来源合同ID")
renewed_from = relationship("Contract", remote_side=[id], foreign_keys=[renewed_from_id])
```

- 原合同：`renewed_from_id = NULL`
- 续期链：A → B → C（B.renewed_from_id = A.id, C.renewed_from_id = B.id）

### 2. 续期流程

```
详情页 [续期] → 创建页(?renew_from=id)
  → 自动回填：客户、计费方式、合同名+(续期)、建议日期
  → 设备默认预选原合同的设备
  → 保存时：
    1. 新合同写入 renewed_from_id
    2. 原合同的 contract_rental 关联迁移到新合同
    3. 原合同保留历史记录
```

### 3. 续期链展示

合同列表页：续期合同显示链路图标 `🔗`（hover 显示全链）

合同详情页：如存在续期关系，展示：
```
续期链路：原始合同 → 续期1 → 续期2（当前）
```
可点击跳转到任意节点。

### 4. 按钮位置

合同详情页 header 操作区，位于「标记回收」后：
```
[编辑] [删除] [发送开通邮件] [发送临期提醒] [标记回收] [续期]
```

## Consequences

### 变容易了
- 续期新建合同一键复制，减少重复录入
- 通过链路追溯完整合同周期
- 设备自动迁移，无需手动重新关联

### 变难了
- 设备迁移逻辑需处理约束冲突（rental_id UNIQUE）
- 续期链查询需递归/CTE

## Reversibility
**高** — `renewed_from_id` 为 NULLABLE，不影响存量数据。回滚只需删除列和迁移。
