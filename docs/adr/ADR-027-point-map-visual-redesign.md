# ADR-027: 点位图视觉重设计（借鉴 NetBox Rack Elevation + Stratora）

## Status
Accepted（纯视觉层重设计，不改数据模型与交互逻辑；关联逻辑后续由用户另行定义）

## Context
ADR-026 层级化点位图功能完备，但视觉被用户判定"太丑"。对照业界成熟产品（NetBox Visual Explorer 的 rack elevation、Stratora Rack Diagrams）调研后，诊断当前 6 个核心问题：
1. **双层表头信息过载**：机柜组头（名称+文字开关+编辑/删除文字按钮+「+机架」）和机架头（名称+容量+编辑/删除）共 6 组文字控件平铺，~100px 高，喧宾夺主
2. **网格平淡无层次**：U 位号列与设备格同一底色同一字重，机架列与机架列之间无边界，看不出"一个机柜是一个物理实体"
3. **设备格视觉权重不足**：小字三行平铺，没有状态指示，与 NetBox 的设备色块差距大
4. **深蓝横幅笨重**：全宽纯深色大色块占 ~50px，信息密度低
5. **操作与状态混排**：编辑/删除是常态可见的文字链接，而它们 95% 的时间不被使用
6. **间距/圆角/阴影缺失**：默认表格感，无卡片化结构

## Decision（视觉规格）

### 0. 设计原则（来自调研）
- **NetBox 哲学**："you are not seeing your datacenter, just data" → 目标是空间可视化，不是数据表格；扁平化、高信息密度、无装饰
- **Stratora 哲学**：状态用**色点/色条**而非大色块文字表达；操作收敛，hover 时才出现；紧凑面板模式（compact mode）
- 操作**默认隐藏、hover 浮现**；状态**一码一色**（点/条），文字退居辅助

### 1. 机柜列 = 轻量卡片
- 每个机架列外轮廓：`1px solid #e8eaed` 边框 + `border-radius: 8px` + 白色背景；列间距 12px（替代原 1px 竖线分列）
- 机架列表头区：浅灰底 `#f7f8fa` 圆角顶，与格区形成层次
- 整排容器：浅灰底 `#f3f5f7` 卡片（`padding 12px`，圆角 12px），机架"立"在浅灰底上——一眼区分物理实体与背景

### 2. 双层表头收敛
- **机柜组头**（第一行）：`机柜名`（600 字重 13px）+ **状态点**（8px 圆点：通电=绿 `#34c759`，未通电=灰 `#c7ccd1`，替代文字开关）+ 右侧 **⋯ 更多** 图标按钮（hover 浮现，下拉菜单：通电/断电切换、编辑、删除、+ 添加机架）。删除原「+机架」文字按钮
- **机架头**（第二行）：`机架名`（12px 600）+ 容量徽标（`1/45` 小灰字，11px，tabular-nums）；**去掉**编辑/删除文字按钮（机架编辑/删除移入该列 hover 时右上角浮现的 2 个 16px 图标：铅笔/垃圾桶）
- 表头总高度从 ~100px 收敛到 ~64px

### 3. U 位格区
- U 位号列：44px，底 `#fafbfc`，字 10px `#9aa3ad` 右对齐；号列与格列之间 1px 浅线
- 设备格：128px，行高 34px，格内 padding 2px 5px
- **已占用格**：圆角 3px 内嵌色块（margin 2px，形成"块"感而非满格填充）：
  - 在用：底 `#e7f4e4`、左侧 2px 状态条 `#34c759`、文字：型号 11px 600 `#2b6b23`（单行省略）+ IP 10px `#7a8a76`；hover 色块加深 + 轻阴影
  - 已断电：底 `#fdecec`、状态条 `#e06c6c`、文字 `#a33` 系
  - （黄色保留给后续关联逻辑，本次不做）
- **空格**：白底无字；hover 时整格浅绿底 + 中央浮现 "+"（12px 绿字）
- 行分隔：`1px solid #f0f1f3`（比现在浅）；列内行高均匀

### 4. 统计横幅 → 紧凑统计条
- 删除全宽深蓝大色块，改为**工具栏内联**：排工具栏左侧 = `A排 · 10柜 · 1/450U 已用` 式灰字统计（12px，数字 600），右侧 = 「+ 添加机柜」primary 按钮（保留白字修复）+「编辑排/删除排」图标按钮（⋯ 下拉或直接图标）
- 横幅若需保留机房级提示（room.note），改为 el-alert light 样式一行

### 5. 页面骨架
- 卡头（机房名 + 添加排）保持 ADR-026 位置不动
- tab 栏（A排/B排/仓库）保持
- 内容区 = 排工具栏（统计+操作）→ 整排浅灰底卡片 → 机架卡片并排（横向滚动）→ 底部 unlocated 提示（样式沿用）

### 6. 交互保留清单（本次不动）
点选空格上架、已占用格跳详情、级联、CRUD 对话框、409 处理、空机柜 2 列占位、hover 浮现的"+"上架入口——全部保留，只改视觉。

## Consequences
**变容易的**：操作入口收敛后表头清爽，状态点比文字开关扫读快 10 倍（Stratora 经验）；卡片化后"机柜=实体"的心智建立；为后续关联逻辑（拖拽上架、健康色叠加、多 U 合并）留好了视觉扩展位（色条/色块结构天然支持）。
**变难的**：hover 浮现交互触屏不可用（内网 PC 场景可接受，⋯ 菜单保留点击路径）；圆角卡片与表格行对齐的实现复杂度略升。

## 可逆性
高：纯 CSS + 模板结构调整，数据与路由零变化。

## 决策记录
- 2026-10-27：用户要求调研业界设计重做点位图 UI（"太丑"）；借鉴 NetBox Visual Explorer（扁平/高信息密度/空间可视化）与 Stratora（状态色点/紧凑模式/操作收敛）；关联逻辑待用户后续给出
